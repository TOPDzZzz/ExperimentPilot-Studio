這是一個非常聰明的路線。**CLI 保證底層工程能力與調試效率，Web 提供產品化體驗與面試展示**，兩者結合後的 `ExperimentPilot` 會比普通單端 Agent 高出一個維度。

為了讓兩份指導書無縫融合，我為你梳理一套**「核心共享 + 雙端適配」**的架構方案，並附上關鍵實現代碼。

## 🔗 2. 四大融合關鍵點

### ① Agent Loop 統一改為 `Generator`（雙端兼容）
CLI 需要逐行打印，Web 需要逐塊更新 UI。生成器是最佳橋樑：
```python
# expilot/core/agent.py
from typing import Generator, Dict, Any
from expilot.core.llm import LLMClient
from expilot.core.tool_router import call_tool

class Agent:
    def __init__(self, max_steps: int = 6):
        self.llm = LLMClient()
        self.max_steps = max_steps

    def run_stream(self, task: str) -> Generator[Dict[str, Any], None, None]:
        history = []
        for step in range(1, self.max_steps + 1):
            action = self.llm.decide(task, history)
            
            if action.action_type == "final":
                yield {"type": "final", "content": action.final_answer}
                return

            if action.action_type == "tool" and action.tool_call:
                tool_name = action.tool_call.tool_name
                args = action.tool_call.arguments
                
                yield {"type": "tool_call", "tool": tool_name, "args": args}
                result = call_tool(tool_name, args)
                yield {"type": "observation", "tool": tool_name, "result": result[:500]}
                
                history.append({"tool": tool_name, "args": args, "result": result})
                continue

        yield {"type": "error", "content": "超出最大執行步數，請縮小任務範圍。"}
```

### ② CLI 端適配（Typer + Rich）
```python
# cli/main.py
import typer
from rich.console import Console
from rich.panel import Panel
from rich.markdown import Markdown
from expilot.core.agent import Agent

app = typer.Typer()
console = Console()

@app.command()
def chat():
    agent = Agent()
    console.print(Panel("🚀 ExperimentPilot CLI Mode", style="bold green"))
    while True:
        task = console.input("\n[bold cyan]Task:[/bold cyan] ").strip()
        if task.lower() in ("exit", "quit"): break

        for step in agent.run_stream(task):
            if step["type"] == "tool_call":
                console.print(f"🛠️ 調用: {step['tool']} | 參數: {step['args']}")
            elif step["type"] == "observation":
                console.print(f"📥 結果: {step['result']}")
            elif step["type"] == "final":
                console.print(Panel(Markdown(step["content"]), title="✅ 最終回答", style="bold magenta"))
```

### ③ Web 端適配（Streamlit + 狀態管理）
```python
# web/app.py
import streamlit as st
from expilot.core.agent import Agent

st.set_page_config(page_title="ExperimentPilot", layout="wide")
if "messages" not in st.session_state: st.session_state.messages = []

# 🔑 避免重複初始化（解決你之前說的「卡頓」問題）
@st.cache_resource
def get_agent():
    return Agent(max_steps=6)

for msg in st.session_state.messages:
    with st.chat_message(msg["role"]): st.markdown(msg["content"])

if task := st.chat_input("輸入任務，例如：分析 experiments/metrics.json 並生成報告"):
    st.session_state.messages.append({"role": "user", "content": task})
    with st.chat_message("user"): st.markdown(task)

    with st.chat_message("assistant"):
        status = st.status("🧠 Agent 執行中...", expanded=True)
        final_box = st.empty()

        agent = get_agent()
        for step in agent.run_stream(task):
            if step["type"] == "final":
                status.update(label="✅ 執行完成", state="complete")
                final_box.markdown(step["content"])
                st.session_state.messages.append({"role": "assistant", "content": step["content"]})
                break
            else:
                with status:
                    st.caption(f"🔹 {step['type'].upper()}: {str(step.get('tool', step.get('content', '')))}")
```

### ④ 工具路由與安全策略統一
將兩份指導書的工具合併，並加入 `workspace` 沙盒限制：
```python
# expilot/core/tool_router.py
from pathlib import Path
from expilot.tools import file_tools, shell_tools, ml_tools, data_tools

WORKSPACE = Path("workspace").resolve()
TOOLS = {
    "list_dir": file_tools.list_dir,
    "read_file": file_tools.read_file,
    "write_file": file_tools.write_file,
    "run_shell": shell_tools.run_shell,
    "summarize_metrics": ml_tools.summarize_json_metrics,
    "analyze_csv": data_tools.analyze_csv,
}

def call_tool(name: str, args: dict) -> str:
    if name not in TOOLS: return f"❌ 未知工具: {name}"
    try:
        return TOOLS[name](**args)
    except Exception as e:
        return f"⚠️ 工具失敗: {e}"
```

## ⚠️ 3. 避坑清單（融合必讀）

| 痛點                               | 解決方案                                                     |
| ---------------------------------- | ------------------------------------------------------------ |
| **Streamlit 每次交互重跑導致卡頓** | 必須用 `@st.cache_resource` 包裹 `Agent()` 與 `OpenAI()`，禁止在 `if task:` 區塊內重複 `load_dotenv()` |
| **LLM 輸出 JSON 不穩定**           | 優先使用 OpenAI `text={"format": {"type": "json_object"}}` + Pydantic 校驗；備用 `try/except JSONDecodeError` 重試 |
| **CLI 與 Web 記憶不同步**          | `memory.py` 統一讀寫 `storage/memory.json`，CLI 直接調用，Web 在 `on_init` 時加載並寫入 `st.session_state` |
| **工具返回內容過長撐爆上下文**     | 所有工具函數內置 `max_chars=800`，超出自動截斷 + `[TRUNCATED]` 提示 |
| **Shell 命令在 Web 端阻塞 UI**     | 高風險命令直接返回 `"⛔ 安全策略攔截"`；Web 端不開放 `require_confirm=True`，改為日誌記錄 |
